The improvement log for the cafe: what shipped, what's queued, what was decided
against and why. The recurring `outbox-cafe-builder` scheduled task (Mini,
Tue+Fri 1pm) reads this before building and appends a batch entry after every
ship. Lives in the repo (not Claude project memory) so the Mini's updates
survive — the laptop pushes its memory snapshot over the Mini's hourly, which
would clobber Mini-side memory edits. Moved here 2026-06-10.

Current alert rule, added 2026-06-26: outbox.cafe cat-signal DMs are off by
default. Historical entries below may mention DMs, but `scripts/cat_signal.py`
now logs and returns false unless `OUTBOX_CAT_SIGNAL_DMS=1` is explicitly set.

So a one-moment infra blip now self-heals via backoff-retry, and a genuinely stuck window degrades to a loud-but-clean exit. `import time` added. The candidate-generation path already caught per-candidate exceptions (returns fewer valid candidates) — only the fallback safety-net had the gap. Verified: compiles on both `/opt/homebrew/bin/python3` and `/usr/bin/python3`; a standalone 4-case control-flow harness confirms the 8am repro (all-fail) now reaches signal+return-2 with backoffs [20,40] instead of crashing, a blip-then-recovery breaks on attempt 2 with one backoff, and the pre-existing bad-output → retry → signal paths are unchanged; `--dry-run` on the Mini rolls spec + assembles prompt clean (exit 0), proving the new import + happy path at runtime.
